# SHAHNEWAZ.EXE

Professional cybersecurity portfolio starter for Shahnewaz Alam.

## Included

- Responsive single-page portfolio
- Anime / cyberpunk-inspired visual system
- Supplied profile photo
- Skills and security-tool sections
- Working email, phone, GitHub, Instagram and YouTube links
- Lightweight CSS/JS animations
- Future-proof structure for later expansion into a business or personal brand

## Run locally

Open `index.html` in a browser.

For a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Edit

Main files:

- `index.html` — content and links
- `style.css` — visual design
- `script.js` — small interactions
- `profile.jpg` — supplied portrait

## Accuracy

The site intentionally avoids inventing certifications, clients, employment history, awards or projects that were not supplied.
